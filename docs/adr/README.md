# Architecture Decision Records

One short file per decision that changes the shape of the project — modules, platforms,
distribution, monetisation, licensing, or a rule every future change must follow.
Numbered, dated, never edited after acceptance: a later ADR supersedes an earlier one.

Format: **Context** (what was true, what changed) · **Decision** (or "provisional" when the
call is not final) · **Consequences** (what code/docs must do now, what is deferred).
